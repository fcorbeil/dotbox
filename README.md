# DotBox

An IPTV player for Windows and Xbox: your channels, movies and series in one guide.

This page is the home of DotBox on the web: the place to **report a problem**, **suggest a feature** and read the **privacy policy**. The app's source code is not published here.

A free GitHub account is needed to write. Please do not put a server address, a user name or a password in a message: everything written here is public.

## What DotBox is

DotBox is a media player. The app includes no content and offers no channels, playlists or subscriptions, free or paid. It plays the sources you add (an M3U playlist or an Xtream account), obtained from the provider of your choice, so what you watch is your responsibility. DotBox is independent of any content provider and invites you to use only sources whose rights holders allow their distribution.

## Features

- Several sources in one guide
- Programme guide
- Movies and series
- Picks up where you left off
- Live pause
- Favorites
- Profiles
- PIN protection
- Search
- Number pad
- Controller, mouse or keyboard
- Windows and Xbox
- Instant start
- Sources and categories of your choice
- Audio description & closed captions
- Multilingual
- Choice of picture format
- Automatic channel and guide updates

## Privacy

See the [privacy policy](PRIVACY.md). In short: DotBox collects nothing and sends nothing to its developer.
